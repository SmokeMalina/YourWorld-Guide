# Настройка фурнитуры

Откройте только [data.js](./data.js). В нём находится вся страница: категории и карточки.

Одна запись в `items` — одна карточка на сайте.

```js
{
  id: "huge_locker",
  name: "Огромный шкаф",
  category: "storage",
  images: [
    "/images/furniture/Огромный_шкаф_1.png",
    "/images/furniture/Огромный_шкаф_2.png",
    "/images/furniture/Огромный_шкаф_3.png"
  ],
  capacity: 1000,
  attachments: [
    { icon: "weapon", name: "Оружие", count: 2 },
    { icon: "firstadkit", name: "Аптечка", count: 1 }
  ]
}
```

- `name` — название карточки.
- `category` — `furniture` или `interior`.
- `images` — одна картинка предмета или все картинки его расцветок. Цвета автоматически станут переключателями одной карточки.
- `capacity` — число слотов; если вместимости нет, укажите `null`.
- `attachments` — разрешённые аттачи. Если их нет, оставьте `[]`.
- `icon` — имя картинки из `images/sets/attach` без `.png`.
- `name` внутри аттача — понятная подпись игроку.
- `count` — количество; для одного слота пишите `1`.

Никаких других файлов, групп, `source` или автоподстановки слотов нет.
