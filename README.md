# YourWorld-Guide

## Поисковый индекс

Поиск на сайте работает на Pagefind. После изменения страниц или данных сайта
обновите индекс перед коммитом командами:

```powershell
npm ci
npm run build:search
```

Добавляйте изменённую папку `pagefind/` в тот же коммит, что и страницы сайта.
Индекс больше не обновляется отдельным коммитом GitHub Actions: такие коммиты
вызывали конфликты при следующем обновлении репозитория через GitHub Desktop.
