# Где редактировать одежду

Единственная рабочая страница — `index.html`. Предпросмотр удалён после переноса дизайна.

## Вместимость сета

1. Откройте `index.html` и найдите название: например, `name: "Al Katala"`.
2. Если есть `versions`, выберите нужную версию по `label: "V1"`, `"V2"` и т. д.
3. В блоке `slots` измените `value` у нужной части комплекта:

```js
slots: [
  { label: "Броня", value: "300" },
  { label: "Куртка", value: "300" },
  { label: "Штаны", value: "300" }
]
```

У предметов без версий блок `slots` находится непосредственно в объекте предмета.
Не путайте `slots` (вместимость) с `attachments` (attach-монты) и `protection` (защита).

Оформление: `styles/pages/outfits-glass.css` относительно корня проекта. Для изменения вместимости CSS менять не нужно.
После изменения данных из корня проекта выполните `npm run build:search`, проверьте страницу и опубликуйте изменения обычным способом.
